Field note 01 / Agents & AI

Engineering agents is really UX engineering

Engineering choices become questions of memory, personality and trust.

Tal PerryMar 09, 202611 min read
In this noteWhat’s insideContext & memoryChoosing toolsMultiple personalities

Over the weekend I built an AI agent. I thought this was an engineering problem, but I now think it is a user experience problem.

In regular software, we solve engineering problems with UX. If a page loads slowly, we show a spinner so the user feels like something is happening.

In agentic software, we create UX problems with engineering decisions.

User trust collapses when the UI and the agent’s memory diverge.

But I am getting ahead of myself. We rent an apartment in Berlin, and as the kids grow we need to rearrange their rooms.
